Kleine Tinker Reitschule – Web-App

Enthalten:
- Startseite mit Ampel 3+/2/1/0-Minus
- Kundenverwaltung
- Kartenbuchung mit Kaufdatum
- Tagesbuchung statt ganze Woche
- Schutz gegen doppelte Buchung pro Kunde/Datum
- Änderung eines gespeicherten Status mit automatischer Rückrechnung
- Sonderregel:
  * Erwachsene / Mutter-Kind / Behindertenreiten
  * 5er-Karte = 1 Gratisabsage
  * 10er-Karte = 2 Gratisabsagen
  * nur bei gültiger Karte (mindestens 1 Reststunde vor Termin)
- Urlaub Reitschule = -1
- G / geschlossen = 0
- JSON-Backup/Import
- PWA-Dateien inkl. Icon und Offline-Grundgerüst

Wichtig:
Die Web-App ist fertig als statisches Paket. Um sie auf dem iPad „Zum Home-Bildschirm“
hinzufügen zu können, muss sie einmal über HTTPS bereitgestellt werden (z. B. kostenlos
über GitHub Pages). Die jetzige Swift-App und deren Daten werden dadurch nicht verändert.
